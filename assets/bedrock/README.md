# Bedrock visual assets

Milestone 10 has started with the separate original Jaguar prototype in `pack/`: a Bedrock client entity, geometry/texture, animation definitions, render controller and synthesized Ogg cues. The optional WildlandsModels Geyser extension registers the entity/phase property and replaces only tagged Jaguar UUIDs for opted-in pack-ready viewers. Java ItemDisplays are not used as the Bedrock renderer. See `docs/MILESTONE-10-PROTOTYPE.md` for installation, version-sensitive negotiation detection and fallback. Client rendering/audio acceptance is deferred; Capybara/Tapir assets are not yet implemented. See `assets/PROVENANCE.md` for editable source.

The combined Milestones 1–9 build relies on Geyser's translation of vanilla containers, blocks, potion consumption, compasses, armor, cooked food, sounds and adult ocelots. Jaguars use the same native server hitbox and equivalent vanilla appearance. No Bedrock resource pack is required or included. All controls are native inventory/main-hand interactions or chat commands; no Java-only keyboard control, mod, offhand requirement or custom inventory packet is introduced.

Java packs are not Bedrock packs. Future custom textures/models require an independently authored Bedrock manifest, item/entity definitions and textures, tested Geyser registration/mapping and fallback behavior when a pack is declined. Verify both editions' controls and hitboxes before claiming parity. Current later-milestone client presentation remains deferred to the collective checklist; these files are representation documentation, not untested pack binaries.
