# Wildlife implementation and verification checkpoint

`0.10.0-wildlife.2` adds Capybara and Tapir to the established Jaguar. The active user goal is broader: finish the animals and their AI/behavior/sounds, verify crossplay and low-end performance, and supply a collective live-test candidate. This checkpoint makes progress toward that goal; it does not redefine or mark it complete. Further ecological species and comprehensive load/interaction checks remain ongoing. Settlement infrastructure is still a separate pending Milestone 10 stage.

## Implemented roster

| Species | Native fallback / authority | Behavior | Presentation |
| --- | --- | --- | --- |
| Jaguar | Named adult ocelot | Existing stalking, territorial warnings, limited chase/bites, native prey hunting, fire/group retreat | Original rosettes, seven voxel parts, phase animations and five synthesized cues |
| Capybara | Named adult pig | Small wetland groups; seeks loaded nearby water, swims locally, gathers with neighbors, forages/rests, retreats when approached/hurt or near fire, returns inside home radius | Stocky brown body, short legs, tiny vestigial tail, swim/forage/retreat poses and distinct chirp/grunt cues |
| Tapir | Named adult pig | Forest habitat; daytime rest, nighttime local foraging, shy avoidance and bounded retreat/home return | Dark body and short trunk, seven voxel parts, forage/retreat poses and distinct whistle cues |

Custom animal feeding/breeding/saddling and native transformation are guarded so pig-based wildlife cannot bypass species/population identity. Untagged vanilla pigs remain ordinary Minecraft animals. Foraging is movement/presentation; it never destroys blocks, crops or player items. Native pig meat remains the fallback drop; no new loot/equipment progression or client mod is introduced.

## Configuration and limits

`wildlife.yml` retains the world list and **shared** limits across the roster: default 32 registered animals per world, 64 loaded, eight decisions per ten-tick callback and one natural-spawn callback per minute. SQLite homes count even when chunks are unloaded. Adding species does not add more AI/spawn schedulers. Natural spawning rotates species and requires loaded, generated habitat and a safe dry location; Capybara additionally needs nearby water and can form a bounded three-member herd. Every herd member independently passes caps and safe-location checks.

`wildlife-expansion.yml` adds independent species enable flags, health, spawn chance, world/cell caps, avoidance range, home radius and fear duration. Defaults: Capybara 12/world, four/cell, 16 health; Tapir eight/world, two/cell, 24 health. These are subordinate to the shared cap, not extra populations on top of it. Disable a species without deleting its chunk entity or saved identity. Reload applies health caps without healing existing animals.

The same finite round-robin queue samples all animals. Nearby water searches cover at most 81 horizontal positions and two heights, checking chunk availability first. Navigation has a loaded corridor guard and one-second minimum request spacing. Runtime gameplay never force-loads chunks or writes SQL per tick.

Fresh `wildlife-visuals.yml` defaults to **12 modeled animals**, 32-block viewing distance and six-tick updates: at most 84 Java model displays plus 12 proxies. Animation is suppressed beyond 16 blocks, and unchanged static transforms/positions are not repeatedly sent. `animate: false` keeps static locomotion presentation while preserving server gameplay. Existing files are preserved; lower an old prototype's 32-model setting explicitly if needed. The animation interval requires restart; view distance/model cap/animation enable can reload. These limits control overhead, not a guarantee of FPS on an arbitrary PC. No human client FPS benchmark is claimed.

Sounds are original, stylized syntheses rather than animal recordings. Per-animal/global throttles remain shared across species. All 15 cues decode to finite, non-silent audio. The exporter canonicalizes Ogg serials/CRCs; all 94 pack source files were regenerated byte-identically. The packs use three 64×64 textures and simple cuboids rather than heavyweight meshes.

## Installation, migration and commands

Use the normal Java 25 build. Install `GGWPWildlands-0.10.0-wildlife.2.jar`, the matching optional `Wildlands-Geyser-Models-0.10.0-wildlife.2.jar` under Geyser's `extensions/`, and its Bedrock `.mcpack` under Geyser's `packs/`. Remove older Wildlands extension/pack copies with the same identifiers. Host the matching Java ZIP and update the configured URL/SHA-1 before enabling it. See MILESTONE-10-PROTOTYPE.md for optional negotiation/fallback and Geyser's forced-pack policy. Current native target remains Paper 26.2 / Java 25 / Geyser 2.11.3 build 1245; no unrelated server version upgrade is made.

Back up the database and worlds together while the server is stopped. Schema **8** adds a species column and defaults old rows to JAGUAR without changing UUID, world or home. It retains the existing prepared/batched writer and verifies legacy schema before migration. Unknown stored species fail closed. Older plugin builds reject schema 8; rollback requires restoring the matching full backup, not replacing only the JAR.

- `/wildlands admin wildlife list` shows species and behavioral state.
- `/wildlands admin wildlife spawn <species> <world> <x> <y> <z>` accepts `jaguar`, `capybara`, `tapir`.
- The old `spawn <world> <x> <y> <z>` form still means Jaguar.
- `/wildlands visuals on|off` is session-only and pack-gated. Without presentation, the named native animal stays visible and uses the same damage/hitbox rules.

## Evidence and remaining work

Automated checks cover species migration/reopen/death, shared world/cell caps, habitats, passive transitions/fear bounds, native-base ownership, each Bedrock definition, model/sound/animation references, display cancellation/fallback and stationary low-traffic rendering. Native probes have created all species/model parts, tested group caps, swimming/foraging/retreat states, and restarted six UUIDs without providers while retaining an injured Tapir's health. See validation/wildlife-expansion-server.md.

Actual Java/Bedrock pack negotiation, visible animation/sound playback and aiming/interaction remain deferred to the collective live session. More animals, full-population/low-end load measurements, mixed-client tracking, deeper integration tests and final delivery readiness remain part of the active goal. Do not interpret file validity or headless state inspection as a passed client test.
